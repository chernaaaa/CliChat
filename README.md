# CliChat

Консольный чат с сетевым взаимодействием по **gRPC** и **Protocol Buffers**: один узел может работать как сервер (приём на порту 8080), другие подключаются к нему как клиенты. Ввод и вывод сообщений ведётся в терминале.

Узнать более подробную информацию и ознакомиться с архитектурной документацией можно [здесь](docs/architecture_documentation.md).

## Требования

- **JDK 21** (или совместимая с Gradle 8.14 версия)
- При первом запуске Gradle скачает зависимости и при необходимости protobuf-компиляторы

## Сборка

Из корня репозитория:

```bash
cd clichat
chmod +x gradlew   # один раз при необходимости
./gradlew build
```

Сборка включает генерацию кода из `src/main/proto`, компиляцию, тесты и Checkstyle.

## Запуск

Сервер слушает порт **8080** (по умолчанию). Клиенту нужны адрес хоста и порт этого сервера.

**Сервер** (имя пользователя обязательно):

```bash
cd clichat
./gradlew run --args="--username alice"
```

**Клиент** (в другом терминале, на той же машине):

```bash
./gradlew run --args="--username bob --peer 127.0.0.1 --port 8080"
```

Если не указать `--peer` и `--port`, приложение стартует в режиме сервера.

Запуск из **IntelliJ IDEA**: откройте каталог `clichat` как Gradle-проект и выполните `Main` с теми же аргументами в конфигурации Run.

## Тесты и проверки

```bash
cd clichat
./gradlew test
./gradlew checkstyleMain
```

Вы также можете ознакомиться с планом тестирования [здесь](docs/testing_plan.md).

## Структура

- `clichat/src/main/java` — основной код (включая `ru.hse.clichat.Main`)
- `clichat/src/main/proto` — описания protobuf/gRPC
- `clichat/config/checkstyle` — правила Checkstyle
