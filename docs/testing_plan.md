# План тестирования P2P чата

## 1. Подход
Базовую логику (парсер, UI) покрываем юнит-тестами (JUnit 5 + Mockito), сеть проверяем руками (E2E).

## 2. План автотестов (Unit)
**Парсер аргументов (`CommandLineArgs`)**
- Запуск сервера (только `--username`).
- Запуск клиента (`--username`, `--peer`, `--port`).
- Ошибки: нет аргументов, нет порта, кривой порт.

**UI и логика (`ConsoleInterface`, `ChatApplication`)**
- Форматирование строки: `[Время] Имя: Текст`.
- Системные сообщения.

## 3. План ручного тестирования (E2E)
1. **Старт сервера:** ждет подключения, не падает.
2. **Коннект:** клиент успешно подключается по адресу/порту.
3. **Чат:** сообщения ходят в обе стороны с правильным именем и временем.
4. **Разрыв:** при отключении клиента сервер пишет "Собеседник отключился" и продолжает работать.
5. **Ошибки сети:** понятная ошибка при попытке подключиться к неверному порту.
